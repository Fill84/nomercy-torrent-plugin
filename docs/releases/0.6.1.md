## NoMercy Torrent Downloader — v0.6.1

Two fixes found on a real server the day after 0.6.0: an episode whose only fitting release is not a
scene release is found now, and LimeTorrents answers again.

### When no release name gives a torrent, the episode is asked for

0.6.0 put only the release names the scene databases gave to the indexers. That misses an episode whose
fitting scene release has no torrent left anywhere, and one that was only ever released outside the scene.
South Park S15E12 was both: its one scene name meeting 1080p, h264 and English only is a 2012 release no
indexer lists, and the 1080p WEB-DL the indexers do have is a P2P release no scene database knows.

- **Release names still go first**, judged by the show's settings, one wish group at a time.
- **When none of them gives a torrent** — no name passed the settings, or no indexer listed a torrent for
  any that did — the indexers are asked for the show and episode, as `South Park S15E12`, in the same
  order: the first-choice indexers one after another, then the rest together.
- **A result counts only when its title names that show, season and episode and nothing more**, and meets
  the show's settings: quality, codec, English only, musts, forbidden, and the releases still refused.
- **The results that count are merged by hash, grouped by the wishes they carry and won exactly as a
  release name's**: the torrent the most indexers list, then the one found first. A result is downloaded
  under its own title.
- An episode that gets no torrent this way either says so on Activity and History, and is searched for
  again on the next run.

### LimeTorrents moved

LimeTorrents moved from `limetorrents.lol` to `limetorrents.fun`. The old address answers with a
redirect, and a plugin may only reach the hosts its manifest names, so LimeTorrents — the third
first-choice indexer — answered nothing. The catalogue and the manifest name the new address; its pages
are read exactly as before.

### Upgrading

Nothing to do. Update through the plugin catalogue; settings, show switches and downloads carry over.
