## NoMercy Torrent Downloader — v0.3.12

One torrent is one grab, and the database is what says so now rather than a
cleanup that ran afterwards.

### The Downloads page stops showing everything twice

A grab is recorded for each episode a cycle decided. Anything that decides the
same episode twice in one pass therefore writes the same info hash twice — and
the index on the hash was not unique, so the table took the second row.

The rule was never enforced. It lived in cleanups: a migration once, and the
maintenance cadence at every start. Between two of those the page showed each
release twice, every step that walked grabs walked both, and a grab that failed
had two rows to put back. On 25 August 2026 three duplicates were cleared at a
start and three more were on the page the same evening — which is what a rule
kept by sweeping up rather than by refusing looks like.

The index is unique now, and the insert says what to do about a torrent already
known: nothing. The first row wins, which is what the earlier migration already
chose — its `grabbed_at` is when the torrent was really taken on, and the covers
it carries are the whole of what that release answers for. A row with no hash is
a decision nothing was handed over, and those stay as many as they need to be.

Duplicates already in the database are cleared when it opens.

The periodic sweep is gone with it. It ran at every start because new duplicates
kept appearing after the migration had cleared the old ones; none can be made
now, so it could only ever find nothing.

### A state of two words reads as two words

The state on a row was the name of the state lower-cased, which ran the words
together: a torrent waiting for its file list said `fetchingmetadata` in the
column an owner reads first to know what a download is doing.

### Everything else

Unchanged from 0.3.11. What the plugin decides, downloads and encodes has not
moved.

### Still outstanding, and not ours to fix

Plugin pages are drawn by the web app inside a shell capped at 64rem, so five of
the Downloads table's nine columns cannot be reached on any display; and a live
push blanks the page rather than swapping the tree, which is the rest of the
flicker 0.3.11 halved. Both are in the web app — filed as
NoMercy-Entertainment/nomercy-app-web#32 and #31.
