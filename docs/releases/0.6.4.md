## NoMercy Torrent Downloader — v0.6.4

Two fixes found on a real server the day 0.6.2 and 0.6.3 came out.

### The buttons keep working after an update

After updating through the catalogue without a restart, every button on the plugin's pages — Cancel, Pause,
Resume, Run, Stop, Save — did nothing. The server attaches a plugin's endpoints once, when it first loads it,
and went on serving the copy it had started with; that copy's endpoints refused the updated plugin.

- **The plugin now has the server serve the updated copy's endpoints as it is loaded.** Updating through the
  catalogue no longer needs a restart for the buttons to answer.
- A server that does not offer this says so in its log; the buttons then answer again after a restart.

The server this version is installed onto may still be serving an older copy's endpoints when 0.6.4 loads.
0.6.4 puts that right itself, the moment it is loaded.

### Another programme of the same name, from indexers without dates

0.6.3 left out what a name source or an indexer dated before the episode aired, but LimeTorrents writes no
dates, and two 2015 Dark Matter releases came through it for the 2024 programme's S02E04:
`Dark Matter S02E04 We Were Family 1080p TrueHD 5 1 AVC REMUX-FraMeSToR` and
`Dark Matter S02E04 1080p WEB x264-FaiLED[PRiME]`.

- **A torrent any indexer dates too old is left out on every indexer that lists it.** The Pirate Bay dates
  FraMeSToR's remux February 2026; LimeTorrents' undated listing of the same torrent is left out with it.
- **Where the name sources show an older programme of the same title, only a dated result counts** in the
  search for the show and episode. Dark Matter S02E04 is answered with the 2015 programme's names from 2016 to
  2023, so an undated result there cannot be told apart and is not taken. A show with no such namesake is
  searched exactly as before.

### Upgrading

Update through the plugin catalogue; settings, show switches and downloads carry over. A download of the wrong
programme that is already running is not stopped by this — cancel it on the Downloads page.
