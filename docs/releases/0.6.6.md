## NoMercy Torrent Downloader — v0.6.6

One fix and two things the pages were missing.

### A batch added by hand is moved, whatever its files call the show

A season pack added by hand finished, showed as finished, and was never moved out of the download folder.
A torrent added by hand is recorded covering no episode — deliberately, because claiming one nobody chose
would put that episode back to missing if the download failed — so what it holds is read from its files
when it finishes. A fansub group names those after an abbreviation: `[Judas] Youjitsu - S04E01v2.mkv` for a
show the library has as *Classroom of the Elite*. No file named a show in any library, so nothing was
staged, nothing was encoded, and 3.7 GB sat there complete.

- **Where a file names no show the owner has, the folder the torrent downloads into is asked** — which is
  the torrent's own name, and a multi-file torrent puts every file under it.
- **A name carrying more than one title is matched on each of them.** A batch is published under the
  romanised title and the English one together, the second in brackets, and the library holds whichever of
  the two it holds. A season, a resolution and a codec are titles no show has, so they match nothing.
- **The longest title a library holds wins.** *Classroom of the Elite* ends in *Elite*, and both are real
  programmes.
- Which episode a file is for still comes from that file's own name, and a torrent whose folder names one
  show while its files name another the owner does have is still placed by its files.

A download that is already sitting finished is taken on at the next pass after the update. Nothing has to be
added again.

### The settings page says which version is answering

The plugin updates from the catalogue without a restart, and nothing in it said which copy was answering —
so whether a fix had landed could only be told from what the plugin did next. At the foot of the settings
page it now names itself and its version, read from the running copy rather than from the manifest on disk.

### A box that finds a show

Eight pages of anime and three of television is no way to find a show.

- **What is typed narrows the list across every library at once**, so neither which library a show is in nor
  which page it was on matters.
- **Part of a title is enough**, and case, accents and punctuation are ignored: `pokemon`, `POKÉMON` and
  `mon hori` all find *Pokémon Horizons: The Series*.
- The box keeps what was typed, a button puts the whole list back, and what is left is paged by what
  matched. Nothing about it is saved: a restart shows every show again.

### Upgrading

Nothing to do. Update through the plugin catalogue; settings, show switches and downloads carry over, and
the buttons keep working without a restart.
