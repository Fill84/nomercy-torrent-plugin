## NoMercy Torrent Downloader — v0.6.3

One fix, found on a real server the morning 0.6.2 came out: another programme of the same name could still
be taken for yours.

### A release name any source dates too old is left out

0.6.2 left out a release name published more than a week before the episode aired — but judged each name
source's copy on its own. Dark Matter's 2015 release `Dark.Matter.S02E04.1080p.WEB.x264-FaiLED` was dated 2016
by PreDB.net and left out there, while PreDB, which writes no dates, and srrDB, whose date was not read, gave
the same name undated. That copy reached the indexers, and the release was grabbed for the 2024 programme's
S02E04.

- **A name is published once.** When any name source dates it more than a week before the episode aired, it is
  left out whichever source gave it.
- **srrDB's search date is read.**
- **A torrent an indexer dates more than a week before the episode aired is not taken for it**, whether it was
  found for a release name or for the show and episode. Torrentz2 dated FaiLED's torrents January 2019.

### Upgrading

Nothing to do. Update through the plugin catalogue; settings, show switches and downloads carry over.
