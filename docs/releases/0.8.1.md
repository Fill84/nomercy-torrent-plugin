## NoMercy Torrent Downloader — v0.8.1

A TV show downloads only a real release, no table scrolls sideways, and Torrentz2 is gone.

### What changed

- **A show downloads only a release the sources name.** An episode of a TV show is downloaded only under
  a release name that PreDB, srrDB, PreDB.net or SceneSource gives. Until one of them names a release, the
  episode waits and the Activity page says why. 0.8.0 searched the indexers for "Show SxxEyy" when no
  source named a release, and took what they had. That is how South Park S29E03 arrived as a non-scene
  HDTV capture three hours before the first real release existed. **Anime is unchanged**: fansubs are the
  real releases there and no name source lists them, so an anime episode is still searched by show and
  episode, Nyaa first.
- **No table scrolls sideways.** Long text in a table cell (a refusal, a reason, a note, a release name, a
  show title or tag list) is cut with "…", and the whole text stands under the table. The filter still
  finds a word that is only in the whole text.
- **Downloads page:** the Destination column is gone (it showed the same folder on every row). Progress is
  the percentage of the size. Rate is the download rate (nothing is uploaded on a public swarm; the
  upload limit in Settings still applies). No figure shows four digits before its unit ("0.98 MB/s").
- **Activity:** the Download stage counts downloads by state. A client's error is on the Downloads page.
- **Torrentz2 is gone** from the sources: its domain no longer exists.
- **The client keeps a healthy peer** when two peers deliver a torrent's first blocks at the same moment.
  Before, that could drop the peer, and a speed limit could be exceeded up to twofold.

### Not in this version

- A wrong episode already delivered by 0.8.0 (South Park S29E03) is not replaced yet. Replacing it
  automatically waits for two fixes in the media server (#599, #600).
- An upload that copies a real release name is still taken when it wins on the indexers. If it holds no
  video it is refused after the download, as before.
- On the Queue page, Attempts and Last tried no longer count up for a show's episode that is waiting on a
  release name, although the name sources are asked every run.

### Upgrading

Install through the plugin catalogue, then restart the server once. The buttons of the copy that was
running stay in place until it does (media-server #60). Nothing needs approving again: the manifest asks
for nothing 0.8.0 did not. Settings, show switches and downloads carry over.
