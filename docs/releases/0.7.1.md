## NoMercy Torrent Downloader — v0.7.1

The plugin no longer reaches into the media server outside the plugin SDK.

### What changed

**After an update while the server runs, restart the server.** 0.7.0 said to press any button twice
after an update through the catalogue: the first press had the plugin re-attach its own buttons by taking
a part of the server that is not in the plugin SDK and rebuilding the server's routes with it. That is a
route into the server the owner can neither see nor revoke, and the plugin contract rules it out, so it is
gone. Until the media server attaches an updated plugin's buttons itself (media-server #60), a plugin
updated while the server runs answers every button with "Restart the server", and a restart puts it
right. The pages are drawn by the updated plugin from the first fetch, as before.

### Upgrading

Install through the plugin catalogue, then restart the server once: the buttons of the copy that was
running stay in place until it does. Nothing needs approving again — the manifest asks for nothing
0.7.0 did not. Settings, show switches and downloads carry over.
