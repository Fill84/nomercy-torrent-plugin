## NoMercy Torrent Downloader — v0.6.5

One fix: a run no longer searches twice.

### A start while a run waits is added to that run, once

A run searches, then stays open while what it grabbed downloads and encodes. A start that arrived in that
time — the Run button, the run interval, a library scan — was marked to search once more, but only a search
reads that mark. Nothing searched, and the mark stayed until the next run, which then searched twice.

- **A start while a run waits on its downloads searches again straight away**, within that run.
- **A start while a run is still searching** still gives one more search once it is done.
- **A new run carries nothing of the last one's**, so it searches exactly once.

### Upgrading

Nothing to do. Update through the plugin catalogue; settings, show switches and downloads carry over, and
the buttons keep working without a restart.
