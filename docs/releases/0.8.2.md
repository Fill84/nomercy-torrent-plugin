## NoMercy Torrent Downloader — v0.8.2

Save, the show switches and every other button on the plugin's pages work again in the web app.

### What changed

- **Every control on the plugin's pages reaches the plugin again.** Since 12 October 2026 the web app
  sends a plugin's button only when its address is a single word, and drops any other without a request
  or a message (web #149, a security fix). Every control here had an address with slashes in it, so from
  that day pressing them did nothing: **Save** on Settings and Sources, switching a show **on or off**,
  the settings of a show or a library, **Find** and its clear, searching one episode from the Queue, and
  **pause, resume and cancel** on Downloads. Only Run, Stop and adding a torrent by hand still worked. Each
  of them now asks for a one-word address, such as `settings-edit` or `shows-84773-on`.
- **The old addresses still answer.** A client that posts to `settings/edit` or `shows/84773/on` reaches
  the same action as before.

### Not in this version

- Anything else. The searching, the sources, the torrent client and the plugin's own browser are those of
  0.8.1. The shows that were switched on before 12 October stayed on and kept downloading; a show switched
  on after it never was, and has to be switched on again.

### Upgrading

Install through the plugin catalogue, then restart the server once. Nothing needs approving again: the
manifest asks for nothing 0.8.1 did not. Settings, show switches and downloads carry over.
