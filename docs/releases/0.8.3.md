## NoMercy Torrent Downloader — v0.8.3

A show the library holds no episode of yet can be found and switched on.

### What changed

- **Find lists a show even when the library holds no file of it.** The overview leaves out every show
  without a single video file, because the server keeps a row for shows nobody added. The only switch is
  on a row of the overview, so a show added to the library and still at 0 episodes — The Ark, 0 of 36 —
  could not be switched on anywhere. Typing part of its title into **Find a show** now lists it, switched
  off, with its own **Switch on** and **Settings** buttons.
- **The whole list is what it was.** Without anything typed, a show with no file is still left out unless
  it is switched on. Once switched on it stays on the list.

### Not in this version

- Anything else. The searching, the sources, the torrent client and the plugin's own browser are those of
  0.8.2.

### Upgrading

Install through the plugin catalogue, then restart the server once. Nothing needs approving again: the
manifest asks for nothing 0.8.2 did not. Settings, show switches and downloads carry over.
